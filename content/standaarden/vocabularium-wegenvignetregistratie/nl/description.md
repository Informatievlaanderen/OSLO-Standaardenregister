Het Vocabularium Wegenvignetregistratie bevat de specifieke termen om wegenvignetregistraties uit te wisselen via een REST API op het MAGDA platform,
zoals de klasse Wegenvignetregistratie en de enveloppe WegenvignetRegistratieEnvelope, die wegenvignetregistraties samen met MAGDA-uitzonderingen uitwisselt.
Generieke termen worden hierin niet opgenomen.
