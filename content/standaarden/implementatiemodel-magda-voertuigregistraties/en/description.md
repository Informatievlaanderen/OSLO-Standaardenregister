The MAGDA Vehicle Registrations Implementation Model, based on the European standard Eucaris,
exchanges vehicle registrations between European member states for the purpose of enforcement.
Vehicle registrations allow owners, keepers, and vehicles to be exchanged for enforcement purposes, for example.
This implementation model is limited to vehicle registrations in the context of enforcement, such as issuing speeding fines
at section controls and other automatic systems that can detect violations. Using the competent services
the data exchanged in order to convert the determination into an effective fine.
The deployment model uses OSLO Person and OSLO Organization to describe the keeper and owner of the vehicle,
The vehicle itself has been reused from Schema.org. More specific terms related to vehicle registrations were
included in a separate vocabulary, separate from the implementation model.
